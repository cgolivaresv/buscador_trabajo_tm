Sincronizar entre dispositivos

Tus marcas (visto, postulé, entrevista, descartes y notas) se guardan en el repositorio, en docs/data/marcas.json. Así las ves iguales en el celular y en el computador, y el buscador deja de avisarte lo que descartaste. Para escribir ahí, cada dispositivo necesita un token de GitHub, que se conecta una sola vez.

  1. Abre github.com → Settings → Fine-grained tokens → Generate new token.
  2. Nombre: Buscador TM. Expiración: la que prefieras (por ejemplo, 1 año).
  3. Repository access: Only select repositories → buscador_trabajo_tm.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Genera el token, cópialo y pégalo aquí.
Si el repositorio es público, cualquiera que lo encuentre puede ver tus marcas y notas. No escribas datos sensibles en las notas.

El token queda guardado solo en este navegador y solo puede modificar archivos de este repositorio.
